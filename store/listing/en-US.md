## Short description

Annotate Windows screenshots and create illustrated guides, directly on your computer.

## Description

SnapSlate turns screenshots into visual explanations. Import an image or use the Windows Snipping Tool while SnapSlate is running, then add text, arrows, shapes, stickers and opaque masks.

The canvas leaves room for your image. Tools stay on the left; steps and properties open when needed. Automatic fitting makes large screenshots easier to work with.

Arrange multiple screenshots into steps, add titles and notes, and export your work as PNG, Markdown, HTML, PDF or Word. Save a SnapSlate project to keep your annotations editable and continue later.

Screenshots and projects are processed locally. Optional Notion and Confluence connections publish text and legends only, when you request it. These connections require an account and permissions for the selected service; local annotation and export require no account.

Automatic clipboard image import is enabled by default and can be disabled in settings. It works while SnapSlate is running. The application does not replace Windows shortcuts when closed.

## Features

- Text, arrows, shapes, stickers and opaque masks.
- Adjustable canvas, cropping, color palettes and opacity.
- Guides with multiple screenshots, titles, notes and legends.
- Local text recognition using the OCR languages installed in Windows.
- PNG, Markdown, HTML, PDF and Word exports.
- Editable projects, undo/redo history and backup of the previous saved version.
- French and English interface.
