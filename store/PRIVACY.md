# Confidentialité de SnapSlate / SnapSlate privacy

Dernière mise à jour / Last updated: 2026-10-28

Cette politique décrit l'application Windows SnapSlate publiée depuis le dépôt [rangornrar/SnapSlate](https://github.com/rangornrar/SnapSlate). Elle ne décrit pas les sites web ni les services externes auxquels l'utilisateur peut choisir de se connecter.

## Français

**Travail local.** SnapSlate importe des captures et images, permet de les annoter, reconnaît du texte avec les composants OCR installés dans Windows et crée des projets et documents sur l'ordinateur de l'utilisateur. L'application n'intègre pas de publicité ni de mesure d'audience et ne demande aucun compte pour ces fonctions.

**Presse-papiers.** L'import automatique des images du presse-papiers fonctionne pendant l'exécution de SnapSlate. Il est activé par défaut et peut être désactivé dans les réglages. Les images importées restent dans la session locale et dans les fichiers que l'utilisateur décide d'enregistrer.

**Stockage.** Les projets, sauvegardes et exports sont enregistrés dans les emplacements choisis par l'utilisateur. Les projets éditables et les sauvegardes `.bak` conservent les images originales, même si un masque est appliqué à l'export. Les réglages, chemins de dossiers et paramètres des connexions sont conservés localement. Des journaux d'erreur locaux contiennent la date, le type d'erreur et son code technique ; SnapSlate ne les transmet pas automatiquement.

**Services facultatifs.** Lorsqu'un utilisateur demande une publication, SnapSlate envoie le texte du guide et ses légendes à l'espace Notion ou Confluence qu'il a configuré. Ces publications n'envoient pas les captures. Les jetons d'accès saisis servent à authentifier ces requêtes et ne sont pas enregistrés dans le fichier de préférences de SnapSlate. L'adresse du service, les identifiants d'espace ou de page et l'adresse de connexion Confluence peuvent être enregistrés dans les réglages locaux. L'utilisation de ces services dépend de leurs propres conditions et politiques de confidentialité.

**Dossiers synchronisés.** L'export vers un dossier SharePoint/OneDrive configuré écrit des fichiers dans ce dossier local. Le logiciel de synchronisation choisi par l'utilisateur peut ensuite les transférer selon sa configuration ; SnapSlate ne gère pas cette synchronisation.

**Contrôle des données.** L'utilisateur choisit les documents qu'il enregistre, publie et partage. Il peut désactiver l'import automatique, ne pas utiliser les connexions externes et effacer ses fichiers locaux. La désinstallation ne supprime pas les projets et exports enregistrés dans ses propres dossiers. Les données déjà publiées sur un service externe se gèrent auprès de ce service. Windows et le Microsoft Store peuvent traiter leurs propres données de fonctionnement selon les paramètres et politiques Microsoft.

**Contact.** Les questions concernant SnapSlate peuvent être adressées via le [dépôt du projet](https://github.com/rangornrar/SnapSlate).

## English

**Local work.** SnapSlate imports screenshots and images, supports annotations, recognizes text using OCR components installed in Windows, and creates projects and documents on the user's computer. The application includes no advertising or audience analytics and requires no account for these features.

**Clipboard.** Automatic clipboard image import operates while SnapSlate is running. It is enabled by default and can be disabled in settings. Imported images remain in the local session and in files the user chooses to save.

**Storage.** Projects, backups and exports are saved to user-selected locations. Editable projects and `.bak` backups retain original images, including when masks are applied to exports. Preferences, folder paths and connection settings are stored locally. Local error logs contain the time, error type and technical error code; SnapSlate does not transmit these logs automatically.

**Optional services.** When the user requests publication, SnapSlate sends guide text and legends to the configured Notion or Confluence workspace. These publications do not send screenshots. Entered access tokens authenticate these requests and are not saved in the SnapSlate preferences file. Service addresses, space or page identifiers and the Confluence login email may be saved in local settings. External services operate under their own terms and privacy policies.

**Synchronized folders.** Exporting to a configured SharePoint/OneDrive folder writes files to that local folder. The user's synchronization software may then transfer them according to its configuration; SnapSlate does not manage that synchronization.

**Data control.** The user chooses which documents to save, publish and share. They can disable automatic import, avoid external connections and remove their local files. Uninstalling the application does not remove projects and exports saved in their own folders. Data already published to an external service is managed through that service. Windows and the Microsoft Store may process their own operational data under Microsoft's settings and policies.

**Contact.** Questions about SnapSlate can be raised through the [project repository](https://github.com/rangornrar/SnapSlate).
